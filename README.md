# 水泥销售记账

一款纯前端、本地存储的水泥销售记账 App，可部署到 GitHub Pages，添加到手机桌面使用。

## 功能

- 新增/编辑/删除销售单据
- 字段：日期、车号、吨位、货物类型（PC/M）、出货人、单价、总金额、付款状态
- 自动计算总金额 = 吨位 × 单价
- 单据筛选与搜索
- 数据统计：总吨位、总销售额、已付/未付金额、按客户统计、付款状态明细查询
- 导出 Excel 备份
- 管理出货人和车号
- 离线可用，数据保存在浏览器 localStorage

## 图标

App 封面为蓝色背景白色“封”字，寓意水泥封存、记账封存。

## 使用

直接访问 GitHub Pages 链接，或下载 `index.html` 用浏览器打开。

## 添加到主屏幕

1. 手机浏览器打开 Pages 链接
2. iPhone：分享 → 添加到主屏幕
3. 安卓：菜单 → 添加到主屏幕 / 安装应用
